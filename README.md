## PlaylistPolice

### An R Package for Intelligent Playlist Analysis

A statistical and machine-learning driven framework for understanding
and optimizing music playlists.

PlaylistPolice goes beyond basic playlist statistics by combining:

- Weighted audio-feature analysis
- PCA and dimensionality reduction
- Clustering and mood classification
- Outlier detection
- Nearest-neighbour based sequencing
- Harmonic compatibility using the Camelot Wheel
- Playlist compatibility analysis

Built as a proper **R package**, rather than just a one-off analysis script.

**Stack:** `R` `Statistics` `Machine Learning` `PCA` `Clustering`

[View Project →](https://github.com/Krishnakd24/PlaylistPolice)
